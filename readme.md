# **Baby Name Project**

### Running the Program
1. Run `main`
2. Follow the prompts displayed in the console.
   + Enter a menu selection (0–11).
   + Enter a name or prefix, if prompted.
   + Enter a sex (A, M, or F), if prompted.
   + Enter a year or year range, if prompted.
3. The program will display the results for both the trie and hash table implementations. 
4. The search time for each data structure will also be displayed.
5. Select 0 at any time to reprint the menu.
6. Select 10 to run the performance benchmark.
   + Displays the insert time for each data structure. 
   + Displays the average execution time for each search operation. 
   + Displays the total search time and overall execution time. 
   + Reports which data structure performed better overall.
7. Select 11 to exit the program.

#### _Thank You!_
